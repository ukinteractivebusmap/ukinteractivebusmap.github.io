Project

UK Interactive Bus Map is a static proof-of-concept for displaying route data from multiple UK bus operators on a single interactive map.

Route Data

Bus route data used in this demo was sourced from publicly available operator and transport datasets.

Map

Interactive mapping provided by Leaflet. Basemap data © OpenStreetMap contributors.

Interface

Interface components and responsive layout provided by Bootstrap.

Disclaimer

This website is a static proof of concept. Route information may be incomplete or outdated and should not be used for journey planning.
